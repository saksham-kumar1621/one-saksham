# One Saksham — Portfolio

> **"Building Things Nobody Asked For."**

A dark-mode, high-fidelity developer and designer portfolio built for **One Saksham**. Featuring smooth GSAP ScrollTrigger animations, HLS background streaming, responsive bento grids, and a multi-page React architecture.

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom HSL Design Tokens + `tailwindcss-animate`
- **Motion & Physics**: [GSAP 3](https://greensock.com/gsap/) (`ScrollTrigger`), [Framer Motion](https://www.framer.com/motion/)
- **Video & Media**: [hls.js](https://github.com/video-dev/hls.js/)
- **Routing**: [React Router DOM v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

---

## 🧭 Pages & Architecture

- **`/` (Home)** — High-impact hero with HLS video, technical architecture bento grid, featured creations, visual explorations with lightbox modal, and metrics.
- **`/projects` (Projects & Lab)** — Filterable and searchable showcase of native desktop tools, Minecraft engines, Git helpers, and real-time apps.
- **`/stack` (Stack & Blueprint)** — Detailed breakdown of core competencies across Frontend, Backend & Systems, AI & Augmented workflows, and DevOps.
- **`/about` (Story & Philosophy)** — The story, design philosophy, and aesthetics behind One Saksham.
- **`/contact` (Dispatch & Connect)** — Direct email dispatch form, 1-click email copy, real-time local time indicator (Muzaffarpur, Bihar), and social links.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/saksham-kumar1621/one-saksham-portfolio.git
cd one-saksham-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your repository.
4. Framework preset will automatically be detected as **Vite**.
5. Click **Deploy**!

SPA route rewrites are configured in `vercel.json`.
